# TronxHub

A comprehensive bilingual educational platform for mechatronics engineering.

## Features
- **Hardware Library**: 26 verified components with technical specs.
- **Projects**: Step-by-step guides with cost estimates and video links.
- **Quiz**: Interactive knowledge checks on engineering fundamentals.
- **TronxBot**: AI technical assistant for engineering queries.
- **Bilingual**: Full English and Arabic support.

## Development
```bash
npm install
npm run dev
```

## Deployment
Automatically deployed to GitHub Pages via GitHub Actions.
